# 🧠 About This Repository

This repository contains laboratory experiments and practical implementations for the **Cloud and Big Data Architecture** course.

The course introduces students to modern cloud computing platforms, virtualization technologies, distributed computing, Hadoop ecosystems, AWS services, Big Data analytics, and real-time stream processing through hands-on experiments.

---

# 🎯 Course Objectives

- ☁️ Understand cloud computing concepts and service models
- 🖥️ Learn virtualization technologies and cloud architecture
- 🌍 Explore public cloud platforms including AWS, Azure and GCP
- 📦 Build Big Data applications using Hadoop ecosystem
- 📊 Understand Stream Analytics and Real-Time Processing
- 🚀 Deploy cloud-native applications
